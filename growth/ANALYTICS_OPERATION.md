# Worldwide GA4 measurement — October 13, 2026

The owner requested automatic GA4 measurement for all visitor regions with an opt-out. The implementation sends **cookieless Consent Mode signals by default worldwide**, not automatic cookie consent. It contains no country allow-list. Cookies are enabled only after an explicit Allow analytics cookies choice or an existing saved permission. Existing Decline choices remain off; Global Privacy Control and Do Not Track block the Google script and are saved as opt-outs.

The default analytics/advertising storage states are queued as denied before Google's script downloads. Google signals and advertising personalization remain disabled. Page views use addresses without query strings. Preference changes do not emit another page view for the same rendered page. Opting out sets Google's disable flag, updates consent, clears accessible first-party GA4 cookies and persists the choice in local storage. An opt-out during script download cannot cause the later ready callback to send a page view. Preview and CMS pages remain untracked.

Cookieless signals still involve processing by Google. They are not a claim of anonymity, a complete count of all visitors, or a guarantee that every visit appears as a Realtime user. Ad blockers, privacy signals, opt-outs and Google's processing/modeling can limit reports. This mechanism does not itself determine the publication's lawful basis in every country. The privacy notice describes the current behavior and links to Google's partner-site data explanation.

References: [Google Consent Mode](https://developers.google.com/tag-platform/security/concepts/consent-mode), [consent-mode implementation](https://developers.google.com/tag-platform/security/guides/consent), [Google user-consent policy](https://www.google.com/about/company/user-consent-policy/).

Validation: 63 unit tests and the Production build passed. Six browser checks with Google traffic stubbed verify automatic consent-denied setup, consent state before script download, explicit cookie permission, no duplicate page view on preference changes, persistent opt-out/cookie removal, saved Decline, GPC/DNT precedence, script-download races and untracked Preview. Stubbed requests verify configuration and application behavior, not actual Google ingestion. Real-tag and deployed checks are recorded separately after completion; ignored evidence stays in `private/growth/`.
